# PartnerPower: working rules for agents

PartnerPower is a mobile app of games for couples to connect with each other. Its code name is
Get Freak, and the two names mean the same project.

## Tone of everything in this repository

This codebase may be shown publicly as a portfolio piece. Keep it safe for work.

- Describe the app as games for couples to connect with each other. Do not describe how mature the
  content is, and do not mention age ratings, in the README, documents, code comments, commit
  messages or pull request text.
- Keep game content, such as dare and question text, in data files apart from the code, so the code
  can be shown without it.
- Use neutral names for code: `category`, `level`, `card`, `deck`. Do not put content words in
  identifiers, file names or test names.

## Where things live

- The plan and tickets are in Linear under the `FRK` team. The ticket is the spec.
